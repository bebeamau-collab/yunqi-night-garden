# 雲棲塔庭 · Night Garden

一座可以慢慢轉動、切換日夜的日式微縮庭園。以原生 HTML、CSS 與 Canvas 2D 等距投影繪製，不需要登入、安裝套件、API Key 或外部素材。

**[開啟線上展示](https://bebeamau-collab.github.io/yunqi-night-garden/)**

## 操作

- **繼續／暫停旋轉**：控制塔樓旋轉與場景裝飾動畫。
- **切換日夜**：切換庭園的光影與配色。
- **重設視角**：回到預設構圖。
- 電腦可拖曳場景，或使用方向鍵調整角度。
- 手機可橫向拖曳旋轉，並上下捲動查看內容。

若裝置啟用了「減少動態效果」，初次開啟會保持靜止；可自行按「繼續旋轉」。

## 本機開啟

下載 `index.html` 後直接以瀏覽器開啟。頁面為單一自包含檔案，不需要建置或伺服器。

## 製作與驗證

這是一個 AI 協作實測作品：主代理提供規格及驗收回饋，Codex CLI 透過 Magpie 路由至 DeepSeek 免費模型完成場景與互動實作，再做增量修正。

已使用 Chromium 驗證桌面、平板與手機尺寸、觸控拖曳、日夜切換、旋轉、暫停、重設、長標題及減少動態設定。手機／平板為瀏覽器模擬測試，並非實體裝置測試。

這個倉庫只包含展示作品，沒有模型帳號設定、API 憑證、原始對話或本機測試紀錄。

## 發布

使用 GitHub Pages，來源為 `main` 分支根目錄。`.nojekyll` 讓 GitHub 直接發布靜態檔案。
